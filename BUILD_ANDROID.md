# Build ExpressDesigner for Android

This document describes how to build, package, and deploy ExpressDesigner as an Android APK.

## Prerequisites

| Component | Version | How to install |
|-----------|---------|----------------|
| **Android SDK** | API 34 | [Android Studio](https://developer.android.com/studio) |
| **Android NDK** | r25+ | SDK Manager → SDK Tools → NDK (Side by side) |
| **Qt for Android** | 6.5+ | [Qt Installer](https://www.qt.io/download) → select Android component |
| **JDK** | 17 | `brew install openjdk@17` (macOS) or via SDK Manager |
| **CMake** | 3.22+ | Included with Android SDK |
| **Ninja** | any | `brew install ninja` (macOS) or via SDK Manager |
| **adb** | any | Included with Android SDK platform-tools |

## Environment setup

Export these variables before building:

```bash
export ANDROID_NDK_ROOT="$HOME/Android/Sdk/ndk/25.2.9519653"
export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
export QT_ANDROID="$HOME/Qt/6.8.0/android_arm64_v8a"
export JAVA_HOME="$(/usr/libexec/java_home -v 17 2>/dev/null || echo /opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home)"
```

> **Tip**: Use `sdkmanager --list` to find your NDK version. Qt Android kits are in `/opt/Qt/<version>/android_<abi>` (macOS) or `~/Qt/<version>/android_<abi>`.

## Build

```bash
# From the project root:
chmod +x build_android.sh
./build_android.sh
```

This produces native `.so` libraries in `build_android/`.

### Custom ABI

```bash
ANDROID_ABI=x86_64 ./build_android.sh   # For emulator
ANDROID_ABI=armeabi-v7a ./build_android.sh
```

Default is `arm64-v8a` (most modern Android devices).

### Release vs Debug

```bash
BUILD_TYPE=Debug ./build_android.sh     # Debug symbols
BUILD_TYPE=Release ./build_android.sh   # Optimized (default)
```

## Package & Deploy

```bash
chmod +x packaging/android/deploy_android.sh
./packaging/android/deploy_android.sh
```

This runs `androiddeployqt` to:
1. Bundle the native library with Qt
2. Generate a signed debug APK
3. Install it on a connected device/emulator via `adb`

### Release APK (signed)

```bash
export ANDROID_KEYSTORE="$HOME/my-release-key.jks"
export ANDROID_KEYALIAS="expressdesigner"
export ANDROID_STOREPASS="your-store-password"
export ANDROID_KEYPASS="your-key-password"

./packaging/android/deploy_android.sh
```

## Limitations

| Feature | Status |
|---------|--------|
| Object creation (Point, Line, Arc, Curve, Custom) | ✅ Works |
| Wavefront propagation | ✅ Works |
| Cartesian oval calculation | ✅ Works |
| Dependency graph (undo/redo) | ✅ Works |
| Project save/load (JSON) | ✅ Works |
| Export TXT / RhinoScript | ✅ Works |
| **STEP/IGES CAD export** | ❌ Disabled (OpenCASCADE not available for Android) |
| Chart visualization | ⚠️ Qt Charts must be installed |
| Touch-friendly UX | ⚠️ Desktop-style UI; touch works but is not optimized |

## Troubleshooting

### `androiddeployqt` not found
Qt Installer layout places it at:
- `$QT_ANDROID/bin/androiddeployqt`
- Or: `~/Qt/Tools/QtCreator/bin/androiddeployqt`

### `cmake` can't find Qt Android
Make sure `CMAKE_PREFIX_PATH` points to your Qt Android directory:
```bash
ls "$QT_ANDROID/lib/cmake/Qt6"  # Should list Qt modules
```

### SISL build fails on Android
The SISL library uses standard C. If it fails, ensure `-fPIC` is enabled (set in `third_party/sisl/CMakeLists.txt` for GCC).

### App crashes on launch
Enable verbose logging:
```bash
adb logcat | grep -E "Qt|ExpressDesigner|AndroidRuntime"
```
